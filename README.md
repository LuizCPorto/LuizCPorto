## 🚀 Projetos em destaque

### 🎓 Módulo de Pós-graduações — ESMAT/TJTO
> Sistema completo de gestão acadêmica desenvolvido do zero. Centraliza matrículas, disciplinas e notas, com sincronização automática com o AVA Moodle via banco de dados — eliminando cadastros manuais.

`C#` `ASP.NET Core MVC` `SQL Server` `Entity Framework` `Moodle`

---

### 🤖 Geração Automática de Certificados com IA
> Funcionalidade que integra a **Vertex AI (Google Cloud)** para validação de dados e geração personalizada de certificados acadêmicos em larga escala, reduzindo drasticamente o tempo de emissão.

`C#` `.NET` `Vertex AI` `Google Cloud` `IA Generativa`

---

### 🔗 Integrações API — TJTO
> Camada de integração robusta entre os sistemas institucionais do TJTO e a plataforma ESMAT via APIs REST, garantindo fluxo de dados automatizado e seguro entre múltiplas plataformas.

`C#` `REST API` `.NET` `SQL`

---

### 🏪 ERP — Dantas Eletro
